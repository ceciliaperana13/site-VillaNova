06 · User Stories

  • US1 — Découvrir les événements : En tant que visiteur Marseillais, je veux voir tous les événements à venir sur la page d'accueil, filtrables par catégorie, pour trouver rapidement ce qui m'intéresse.
  • US2 — Consulter un événement : En tant que visiteur intéressé, je veux accéder à la fiche détaillée d'un événement (programme, lieu, tarif, accessibilité) pour décider si je souhaite y participer.
  • US3 — Réserver une place : En tant que participant confirmé, je veux réserver ma place en ligne depuis la fiche événement pour être sûr d'avoir accès à la manifestation.
  • US4 — Accessibilité sourds/malentendants : En tant que personne malentendante, je veux voir quels événements proposent LSF ou sous-titrage, pour choisir des événements adaptés à mes besoins.
  • US5 — S'informer via mobile : En tant que visiteur sur smartphone, je veux naviguer facilement sur le site (menu burger, cartes lisibles, boutons accessibles) pour trouver des événements en déplacement.

08 · Loi de Miller — 7 éléments apparents par page

1 — Navigation

Header avec 5 liens max + CTA (Accueil, Événements, Agenda, Carte, Contact)

2 — Filtres catégories

7 filtres : Tous, Concerts, Expos, Festivals, Théâtre, Gastro, Sport

09 · Éco-conception numérique

Images lazy loading

Attribut loading="lazy" sur toutes les images hors-écran. Format WebP recommandé.

2 polices max

Playfair Display + DM Sans uniquement. Preconnect Google Fonts pour accélérer le chargement.

CSS natif

Zéro framework CSS. Variables CSS natives. Animations CSS uniquement (pas de librairie JS animation).

JS minimal

Vanilla JS uniquement. Pas de jQuery. Code asynchrone avec async/await.

Vidéo preload="none"

Les vidéos ne se chargent qu'au clic de l'utilisateur, évitant les transferts inutiles.

prefers-reduced-motion

Toutes les animations sont désactivées si l'utilisateur a configuré ce préférence système.
